# v0.1.0-rc.1 Release Checklist

## Objective

Publish the first public norm-spec release candidate from one exact commit,
then prove the GitHub, binary, crates.io, Rust-consumer, and canonical Skill
paths before considering stable `v0.1.0`.

D017 defines the release order, exact-identity rule, partial-publication
handling, and maintainer checkpoints. This checklist records execution evidence;
it does not grant publication authority.

## Stable promotion criteria

`v0.1.0` remains a separate maintainer decision. Promotion requires:

- every Phase 7 public path green;
- no unresolved format, engine, CLI, package, artifact, installation, or Skill
  blocker found during RC use;
- any necessary fix published as another RC and revalidated;
- no new feature scope in the stable promotion diff;
- a fresh exact stable commit, complete hosted run, four stable-version
  archives, changelog entry, annotated tag, GitHub Release, and serial crate
  publication using the same identity rules.
